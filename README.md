# presentation-design — скилл для деловых презентаций

Скилл для AI-агента: сборка и проверка деловой презентации. Даёт методику оформления,
самодостаточную HTML-деку, ветку PPTX и — главное — **реестр цифр с машинной проверкой
согласованности**.

Презентации рассыпаются не из-за дизайна, а потому что одно и то же число записано руками
в нескольких местах: поправил в одном — остальные остались старыми. Здесь каждое число живёт
один раз, в реестре `facts.json`; в слайдах оно только отображается через `data-fact`.

## Состав

```
SKILL.md                          методика: 11 разделов
scripts/check_deck.py             проверка и правка согласованности (Python 3.8+, stdlib)
references/facts-and-markup.md    схема facts.json + все коды проверок
references/consistency-checklist.md  что проверяется чтением
assets/template.html              каркас деки
assets/example/deck.html          7 слайдов: титул, вывод, данные, 2 находки, рекомендации, что дальше
assets/example/facts.json         14 фактов, из них 6 производных
```

## Как работает

```
python scripts/check_deck.py sync  deck.html facts.json          # подставить числа, обновить счётчик
python scripts/check_deck.py check deck.html facts.json          # проверить: цель — 0 ошибок
python scripts/check_deck.py where deck.html facts.json <id>     # где факт и что от него зависит
python scripts/check_deck.py grep  deck.html "текст или regex"   # найти устаревшие формулировки
```

Доказательство на примере: CPA поиска «800 ₽» встречается в `assets/example/deck.html`
**2 раза**, производный разрыв «25 %» — **3 раза**. Поправить число руками в одном месте →
`check` даёт `E-FACT-TEXT`. Поправить в реестре и запустить `sync` → обновлено **5 мест
одним действием**, разрыв пересчитан сам (25 % → 33 %).

`check` ловит: число на экране против реестра, счётчик слайдов, ссылку в никуда, оглавление
против названий, текст «слайд N» против реального номера, заполнители, внешние ресурсы,
переполнение по лимитам, слово о росте против знака факта, число вне реестра.
Всего 17 кодов ошибок и 16 предупреждений.

## Что внутри методики

Палитра ролями и правило доминанты · архитектура слайдов (сендвич, роли `title/summary/
method/finding/recommendation/next/appendix`) · типографика и проверка на перекрытие ·
сводный график с несколькими осями · честность цифр (охват суммы, обязательный слайд
допущений, три сценария чувствительности со сглаживанием выбросов, факт против прогноза) ·
ветка PPTX (python-pptx) · финальные ворота перед выдачей.

## Быстрый старт

1. Скопируй `assets/template.html` в рабочую папку.
2. Создай `facts.json` — все числа, производные задавай формулой `derive`.
3. Собери слайды, каждое число — `<span data-fact="id">`.
4. `sync`, затем `check` до нуля ошибок.
5. Открой деку с `?debug` — переполненные слайды получат красную рамку.

Требования: Python 3.8+ (только стандартная библиотека). Внешних зависимостей нет.

## Проверено

- `check` на `assets/example/deck.html` → **0 ошибок, 0 предупреждений, 7 слайдов, 14 фактов**.
- `sync` после сборки примера → 0 изменений (числа посчитаны теми же функциями, что и реестр).
- Дека-пример самодостаточна: ни внешних скриптов, ни стилей, ни ссылок в интернет.
