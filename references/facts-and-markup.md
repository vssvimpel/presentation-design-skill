# Реестр фактов, разметка и коды проверок

## facts.json

```json
{
  "meta": {"decimal": ",", "report": "Название отчёта"},
  "facts": {
    "cost_search":  {"label": "Расход, поиск", "value": 1200000, "unit": "₽", "period": "2026-09"},
    "pay_search":   {"label": "Оплаты, поиск", "value": 1500, "period": "2026-09"},
    "cpa_search":   {"label": "CPA, поиск", "derive": "cost_search / pay_search", "unit": "₽", "period": "2026-09", "key": true},
    "cpa_search_yoy_pct": {"label": "Изменение CPA к прошлому году", "value": -6.4, "unit": "%", "decimals": 1, "period": "2026-09"}
  }
}
```

Поля факта:

| Поле | Значение |
|---|---|
| `label` | человекочитаемое название (нужно для понятных сообщений проверки) |
| `value` | число или строка. Для производного факта не задаётся |
| `derive` | формула из `+ - * /`, скобок, чисел и id других фактов. Считается автоматически |
| `unit` | единица, добавляется к числу: `₽`, `%`, `млн ₽`, `шт.` |
| `unit_sep` | разделитель между числом и единицей. По умолчанию: пустой для `%`, неразрывный пробел для остальных |
| `decimals` | знаков после запятой (по умолчанию 0) |
| `scale` | на сколько делить значение при показе (`1000000` для «млн»); в реестре хранится полное значение |
| `signed` | показывать «+» у положительных чисел (для изменений) |
| `period` | период факта, строка. Если слайд имеет `data-period` и он отличается, будет предупреждение |
| `key` | ключевой факт: обязан быть на итоговом слайде и подтверждён на слайде с данными |

Правила:

- id факта: латиница, цифры, `_`, не начинается с цифры. Выбирай осмысленные id (`cpa_search`), а не `F1`. Так их не спутать с id находок `F1…F5` из JSON аналитика.
- Производные метрики всегда через `derive`. Тогда изменение исходного числа обновляет и CPA, и ДРР, и разницы.
- Текстовые факты (`"value": "Поиск"`) допустимы для названий, которые повторяются в нескольких местах.
- Минус отображается как «−» (U+2212). Проверка считает «-», «−», «–» одинаковыми.

## Атрибуты разметки

| Атрибут | Где | Назначение |
|---|---|---|
| `id="sN"` | `section.slide` | строго `s1…sN` по порядку |
| `data-title` | `section.slide` | каноническое название; обязано совпадать с первым `h1/h2` и с текстом в оглавлении |
| `data-role` | `section.slide` | `title`, `summary`, `method`, `finding`, `recommendation`, `next`, `appendix`. Роль `summary` нужна для проверки ключевых фактов |
| `data-period` | `section.slide` | период данных на слайде, сверяется с `period` фактов |
| `data-fact="id"` | `span`, `td`, `b` и др. | показывает значение факта; внутри только текст, без вложенных тегов |
| `data-trend="id"` | абзац, `li` | текст со словами «вырос/снизился» сверяется со знаком факта |
| `data-static` | любой | число не является метрикой, не предупреждать |
| `data-agenda` | `ol`/`ul` | оглавление: тексты ссылок сверяются с названиями слайдов |
| `data-total-slides` | `span` | общее число слайдов; обновляется `sync` |
| `data-slide-num` | `span` | заполняется скриптом страницы при показе |
| `data-decor` | `img` | декоративная картинка без `alt` |

## Коды проверок

| Код | Что значит | Как исправить |
|---|---|---|
| `E-REG-ID`, `E-REG-CALC` | ошибка в реестре: плохой id, формула, цикл, деление на ноль | поправь `facts.json` |
| `E-SLIDE-ID` | `id` слайда не `sN` по порядку | перенумеруй `id`, потом ссылки и оглавление |
| `E-TITLE` | заголовок слайда не совпадает с `data-title` | приведи к одному тексту |
| `E-TOTAL` | счётчик слайдов устарел | `sync` |
| `E-LINK` | ссылка `#sN` ведёт в никуда | исправь ссылку или верни слайд |
| `E-AGENDA` | оглавление не совпадает с названием слайда | исправь текст пункта |
| `E-SLIDEREF` | «слайд N» вне диапазона или не совпадает со ссылкой | исправь номер и ссылку вместе |
| `E-FACT-UNKNOWN` | в `data-fact` id, которого нет в реестре | добавь факт или исправь id |
| `E-FACT-NESTED` | внутри `data-fact` вложенные теги | оставь только текст |
| `E-FACT-TEXT` | показанное число не совпадает с реестром | `sync` |
| `E-KEY` | ключевой факт не вынесен на итоговый слайд (или нет итогового слайда) | добавь факт на слайд `summary` |
| `E-TREND` | слова о росте или снижении противоречат знаку факта | перепиши фразу или проверь значение |
| `E-PLACEHOLDER` | остался заполнитель | замени текстом или убери |
| `E-EMPTY`, `E-DUPID`, `E-NOSLIDES` | пустой слайд, повторный `id`, нет слайдов | исправь структуру |
| `W-UNTRACKED-FACT` | число совпадает с фактом, но набрано руками | оберни в `data-fact` |
| `W-UNTRACKED` | числа в тексте, которых нет в реестре | занеси в реестр или пометь `data-static` |
| `W-UNUSED` | факт нигде не используется | удали из реестра, если слайд убрали намеренно |
| `W-KEY-EVIDENCE` | ключевой факт только в выводах, без подтверждения | добавь на слайд с данными |
| `W-PERIOD` | период факта и слайда различаются | проверь, тот ли это период |
| `W-DENSE` | слишком много слов, пунктов или строк | раздели слайд или вынеси в приложение |
| `W-NOTITLE`, `W-NOHEAD`, `W-DUPTITLE` | нет `data-title`, нет заголовка, повтор названия | дополни |
| `W-AGENDA-MISSING`, `W-AGENDA-ORDER` | слайда нет в оглавлении, порядок не совпадает | обнови оглавление |
| `W-EXT`, `W-ALT` | внешний ресурс, картинка без `alt` | встрой в файл, добавь описание |
| `W-TREND`, `W-REG-STALE`, `W-REG-LABEL` | неоднозначный текст тренда, лишнее `value` у производного факта, нет `label` | уточни |

## Команды

```
python scripts/check_deck.py check deck.html facts.json [--json] [--strict] [--max-words N] [--max-bullets N] [--max-rows N]
python scripts/check_deck.py sync  deck.html facts.json [--dry-run]
python scripts/check_deck.py where deck.html facts.json <fact_id>
python scripts/check_deck.py grep  deck.html "текст или regex"
```

`check` возвращает код 1 при ошибках (и при предупреждениях с `--strict`). `sync` меняет текст только внутри размеченных элементов и счётчиков, остальное не трогает. `grep` ищет по видимому тексту слайдов и показывает номер слайда с контекстом.

Ограничения скрипта: он не видит смысла. Он не проверит, что вывод логически следует из таблицы, что рекомендация относится к существующей находке и что число в графике-картинке совпадает с числом в тексте. Для этого есть чек-лист чтением.
